# WAFT YouTube Channel

Content planning and production materials for the WAFT YouTube series.

## Directory Structure

```
youtube/
├── episodes/       # Episode outlines and planning docs
├── scripts/        # Full script drafts
├── shot-lists/     # Camera and B-roll planning
└── assets/         # Graphics, thumbnails, etc.
```

## Series Concept

Building a modular, evolvable digital pet system in public. Part technical deep-dive, part creative exploration.

## Episode Pipeline

1. **Outline** → `episodes/epXX-title.md`
2. **Script Draft** → `scripts/epXX-script-draft.md`
3. **Shot List** → `shot-lists/epXX-shots.md`
4. **Record** → Raw footage
5. **Edit** → Final cut
6. **Publish**
