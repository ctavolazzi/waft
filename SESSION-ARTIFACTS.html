🚀 How to Access This Work

Follow these steps to get this code on your local machine:

# Clone the repository (if you haven't already)
git clone https://github.com/ctavolazzi/waft.git
cd waft

# Pull the latest changes from this branch
git fetch origin claude/go-to-town-vWLDW
git checkout claude/go-to-town-vWLDW
git pull

# Install dependencies and run tests
cd visualizer
npm install
npm test

# View the experimental paper
open ../docs/experiment-paper.html
# or just double-click docs/experiment-paper.html in your file browser!

All artifacts are committed and pushed to the remote repository. The HTML paper will work offline and can be viewed directly in any browser!
