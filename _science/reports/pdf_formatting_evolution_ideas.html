PDF Formatting Evolution: Common First-Time Mistakes

Introduction

This document explores common PDF formatting mistakes that anyone would make on their first go around. These are the easy mistakes - the ones that seem obvious in hindsight but trip up everyone initially.

1. List Spacing Issues

Problem

Lists often have inconsistent vertical rhythm:

  • List items too close together or too far apart
  • No spacing between list and surrounding paragraphs
  • Nested lists lose proper indentation hierarchy

Ideas for Improvement

  1. Add consistent top/bottom margins to ul/ol
  • Match paragraph spacing for visual consistency
  • Ensure lists don't feel disconnected from content
  1. Increase list item spacing
  • Use margin-bottom: paragraph_spacing / 2 instead of /3
  • Better visual separation between items
  1. Improve nested list indentation
  • First level: 20pt padding
  • Second level: 30pt padding
  • Third level: 40pt padding
  • Clear visual hierarchy

2. Code Block Line Breaks

Problem

Code blocks don't preserve line breaks properly:

  • Multi-line code gets squished
  • Indentation lost
  • Code becomes unreadable

Ideas for Improvement

  1. Add white-space: pre-wrap to pre blocks
  • Preserves line breaks
  • Allows wrapping for long lines
  1. Ensure code inside pre preserves formatting
  • Use white-space: pre for exact formatting
  • Display as block for proper rendering

Example

Before:

def test():

return True

After (with proper formatting):

def test():

    return True

3. Blockquote Styling

Problem

Blockquotes (> quote) aren't styled:

  • No visual distinction from regular paragraphs
  • Missing left border and background
  • Hard to identify as quotes

Ideas for Improvement

  1. Add left border (4pt solid accent color)
  2. Use subtle background (20% opacity code background)
  3. Indent from left margin (proper padding)
  4. Italic text for visual distinction

5. Header Spacing

Problem

Headers often have awkward spacing:

  • Too much space after header
  • First paragraph feels disconnected
  • Headers break visual flow

Ideas for Improvement

  1. Reduce header margin-bottom slightly (use 0.75x paragraph spacing)
  2. Add margin-top to first content after header (0.5x paragraph spacing)
  3. Ensure headers connect to content

6. Horizontal Rules

Problem

Horizontal rules (---) often have no spacing:

  • Rules feel cramped
  • Need breathing room above and below

Ideas for Improvement

  1. Add margin-top and margin-bottom to hr elements
  2. Match paragraph spacing for visual consistency

7. Table Cell Padding

Problem

Table cells have minimal padding (4pt):

  • Text feels cramped
  • Need more breathing room

Ideas for Improvement

  1. Increase padding to 6-8pt
  2. Ensure consistent spacing

---

8. Code Inline vs Block

Problem

Inline code and code blocks look too similar:

  • Both use same background color
  • Hard to distinguish

Ideas for Improvement

  1. Make inline code subtle (80% opacity background, smaller padding)
  2. Make code blocks prominent (full opacity, larger padding, border)

Example

Inline code: const x = 42; (subtle)

Code block (prominent):

const x = 42;

const y = x * 2;

Problem

Empty paragraphs (

) create awkward spacing:

  • Multiple empty lines create gaps
  • Should collapse empty paragraphs

Ideas for Improvement

  2. Or ensure markdown conversion doesn't create empty paragraphs
