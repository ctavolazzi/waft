## Three PDF Generation Systems

### 1. Template System (PRODUCTION) ⭐
**Location:** `src/waft/templates/`
- `field_guide.py` - Field guide template
- `lab_notes.py` - Lab notebook template  
- `personal_memo.py` - Personal memo template
- `tm_report.py` - Technical memo template

**Technology:** WeasyPrint + HTML + Jinja2  
**Status:** ✅ Production, proven, working  
**Used by:**
- `examples/generate_waft_field_guide.py`
- `examples/generate_template_showcase.py`
- `examples/advanced_demo/advanced_demo.py`
- `tools/framework_documentation/generate_framework_docs.py`

**How it works:**
- HTML content with CSS styling
- Jinja2 templates for dynamic content
- WeasyPrint converts HTML to PDF
- Handles formatting automatically (word wrap, page breaks, typography)

**Pros:**
- ✅ Beautiful, professional output
- ✅ Automatic formatting (no manual positioning)
- ✅ Flexible layouts (CSS)
- ✅ Production-ready and tested
- ✅ Used by all showcase examples

**Cons:**
- Requires HTML knowledge
- System dependencies (Cairo, Pango for WeasyPrint)

---

### 2. Foundation V1 (PRODUCTION)
**Location:** `src/waft/foundation.py`

**Technology:** FPDF2 (pure Python)  
**Status:** ✅ Production  
**Used by:**
- `scripts/generate_documentation_pdfs.py` - Markdown to PDF converter
- `src/waft/verify_foundation.py` - Foundation verification
- `src/waft/generate_artifacts.py` - Artifact generation

**How it works:**
- Block-based API (SectionHeader, TextBlock, LogBlock, etc.)
- Manual positioning and layout
- Markdown parsing to blocks
- Direct FPDF2 rendering

**Pros:**
- ✅ Pure Python (no system dependencies)
- ✅ Simple API
- ✅ Lightweight

**Cons:**
- ❌ Manual positioning required
- ❌ Limited automatic text flow (needs `multi_cell` fix)
- ❌ Basic typography
- ❌ Formatting issues (the problem we're seeing)

**Current Issue:**
- TextBlock uses manual word wrapping with `pdf.text()` which doesn't handle:
  - Word wrapping within margins
  - Line spacing properly
  - Page breaks automatically
  - Y positioning correctly

**Fix Applied:**
- Changed to use `pdf.multi_cell()` which handles all of the above automatically

## The Problem

**File:** `WAFT_Research_Example_A_Mac_Shortcuts.pdf`  
**Generated by:** `scripts/generate_documentation_pdfs.py`  
**System:** Foundation V1  
**Issue:** Poor formatting (text not wrapping, spacing issues)

**Root Cause:**
- `TextBlock.render()` in `foundation.py` uses manual word wrapping with `pdf.text()`
- This doesn't handle word wrapping, line spacing, or page breaks properly
- Should use `pdf.multi_cell()` instead
