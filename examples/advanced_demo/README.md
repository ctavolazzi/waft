# WAFT Advanced Demonstration

This advanced demo showcases WAFT's powerful self-documentation and organization capabilities.

## What It Demonstrates

### 1. Framework Self-Documentation
- WAFT inspects its own codebase
- Generates comprehensive documentation
- **NO HARDCODED CONTENT** - everything is discovered through analysis
- Demonstrates recursive self-documentation

### 2. PDF Binder Organization
- Recursively scans directories for PDFs
- Extracts metadata (title, author, pages, dates)
- Organizes into intelligent booklets (max 25 pages each)
- Creates full binder with all PDFs
- Saves comprehensive metadata to JSON

### 3. Meta-Cognitive Integration
- Shows how tools integrate with WAFT's _pyrite system
- Demonstrates recursive improvement loops
- Explains the connection between documentation and self-improvement

## Running the Demo

```bash
python3 examples/advanced_demo/advanced_demo.py
```

## Output

The demo creates:
- `advanced_demo_output/` - Main demo folder
  - `WAFT_Framework_Documentation.pdf` - Self-generated framework docs
  - `organized_pdfs/` - PDF organization results
    - `FULL_BINDER.pdf` - Complete binder
    - `booklet_*.pdf` - Individual booklets
    - `metadata.json` - Comprehensive metadata
  - `advanced_tools_integration.md` - Integration explanation
  - `WAFT_Advanced_Demo_Booklet.pdf` - Complete demo documentation

## Key Features

- **Self-Documentation**: WAFT describes itself
- **Intelligent Organization**: Smart PDF booklet assembly
- **Meta-Cognitive**: Integration with epistemic memory
- **Recursive**: Creates feedback loops for improvement

## The Recursive Loop

1. WAFT generates documents → Creates PDFs
2. WAFT organizes documents → Creates binders
3. WAFT documents itself → Creates framework docs
4. WAFT tracks its work → Uses _pyrite
5. WAFT improves → Based on observations
6. Cycle repeats → Continuous enhancement

This is **recursive self-improvement through documentation and organization**.
