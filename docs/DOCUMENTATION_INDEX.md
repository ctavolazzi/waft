## 📖 What is WAFT?

**WAFT** (Wave Agent Framework & Tools) is a Python framework for **directed evolution of self-modifying AI agents**. Think of it as a scientific laboratory where AI agents can:

- **Evolve** through genetic mutations (code changes)
- **Compete** in fitness tests (Scint Gym)
- **Reproduce** by spawning variants
- **Learn** from their evolutionary history

### The Core Philosophy

> **"Don't just build agents. Breed them."**

WAFT treats agent code as DNA, allowing systematic evolution through natural selection. It's a scientific instrument for studying the **physics of artificial cognition**.

### Key Features at a Glance

- 🧬 **Genetic Evolution**: Code as DNA with SHA-256 genome IDs
- 🎯 **Fitness Functions**: Reality Fracture Detection (Scint System)
- 📊 **Flight Recorder**: Complete phylogenetic tree tracking
- 🎲 **D&D Gamification**: RPG mechanics for engagement
- 📄 **PDF Generation**: 14+ professional document templates
- 🖥️ **Desktop Apps**: Electron-based application system
- 🧠 **Epistemic Tracking**: Knowledge measurement (Empirica)
- ⚡ **Self-Modification**: Agents that evolve their own code
