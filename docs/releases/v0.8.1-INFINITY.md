## Major Features

### 🔬 Science-Bitch: Spacetime Context & Artifacts

#### The Revolutionary Change

**Before v0.8.1**: Science-Bitch generated reports with research findings.

**After v0.8.1**: Science-Bitch creates **artifacts** - complete, verifiable, contextual records of research that include:
- The research findings
- The complete state of the system when research was conducted
- Visual exhibits (screenshots, evidence)
- Verifiable metadata (generation IDs, timestamps)

#### Spacetime Context Capture

**What It Captures**:

1. **Artifact Metadata**
   - Unique generation ID (SHA-256 hash)
   - Timestamp (ISO 8601 with timezone)
   - Project name and path
   - Working directory

2. **Git State**
   - Current branch
   - Latest commit hash
   - Commit message
   - Uncommitted files count
   - Recent commits (last 5)
   - Remote repository info
   - Commits ahead/behind origin

3. **System State**
   - Platform (macOS, Linux, Windows)
   - Python version
   - Working directory
   - Disk usage
   - System information

4. **Project State**
   - Active work efforts (heuristic detection)
   - Recent files (modified in last 24 hours)
   - Project structure information

5. **Environment State**
   - PYTHONPATH
   - VIRTUAL_ENV
   - CONDA_DEFAULT_ENV
   - USER, HOME
   - WAFT-specific environment variables

#### Artifact Metadata System

Every Science-Bitch artifact now includes:

- **Generation ID**: Unique identifier for this artifact
- **Spacetime Coordinates**: When and where this artifact was created
- **Invocation Context**: What was happening when Science-Bitch was invoked
- **System Snapshot**: Complete state of the system at that moment
- **Verifiable Exhibits**: Screenshots and visual evidence

#### Enhanced PDF Reports

**Academic Paper Template** now includes:

- **Artifact Metadata Section**: Complete context on cover page
- **Exhibits System**: Visual evidence (Exhibit A, B, C...)
- **Contextual Abstracts**: Abstracts include invocation point data
- **Professional Formatting**: Academic-style layout with metadata

**Files Modified**:
- `src/waft/core/science_bitch.py` - Context capture system
- `src/waft/templates/academic_paper.py` - Artifact metadata display
- `_science/tools/generate_contextual_pdf.py` - Standalone contextual PDF generator
