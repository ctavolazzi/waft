## CASCADE Workflow Reference

### The 5-Step Workflow

```
1. PREFLIGHT → 2. INVESTIGATE → 3. CHECK → 4. ACT → 5. POSTFLIGHT
```

### Phase Descriptions

#### 1. PREFLIGHT 📊
- **Purpose**: Assess current epistemic state
- **What it does**:
  - Retrieves current epistemic state from Empirica
  - Calculates KNOW and UNCERTAINTY levels
  - Determines if investigation is required
  - Submits preflight assessment to Empirica
- **Output**: `KNOW: X%, UNCERTAINTY: Y% → INVESTIGATE REQUIRED/OK`

#### 2. INVESTIGATE 🔍
- **Purpose**: Reduce uncertainty by logging findings and reviewing past experiences
- **What it does**:
  - Reflects on past similar consultations (searches memory)
  - Reviews relevant insights from journal
  - Analyzes learned patterns for current phase
  - Tracks epistemic trajectory (improving/declining/clarifying)
  - Logs findings and unknowns to Empirica
- **Commands**: `empirica finding-log`, `empirica unknown-log`

#### 3. CHECK ✅
- **Purpose**: Decision gate based on findings and remaining unknowns
- **What it does**:
  - Calculates confidence based on findings vs unknowns
  - Considers uncertainty level
  - Submits CHECK gate to Empirica
  - Gets decision: PROCEED | HALT | BRANCH | REVISE
- **Decision Logic**:
  - **PROCEED**: Confidence ≥ 0.7 AND uncertainty < 0.3
  - **HALT**: Confidence < 0.3 OR uncertainty > 0.7
  - **BRANCH**: More unknowns than findings (needs investigation)
  - **REVISE**: Otherwise (needs refinement)

#### 4. ACT 🎯
- **Purpose**: Execute with precision - generate recommendation
- **What it does**:
  - Generates recommendation based on epistemic phase, knowledge coverage, findings, unknowns, reflection insights, check decision, learned patterns
  - Applies personality styling
  - Incorporates check decision into recommendation text
- **Output**: `[PROCEED/HALT/BRANCH/REVISE] Recommendation text...`

#### 5. POSTFLIGHT 📈
- **Purpose**: Measure learning deltas and verify calibration
- **What it does**:
  - Calculates learning deltas (knowledge change, uncertainty change)
  - Submits postflight assessment to Empirica
  - Logs consultation to journal (for memory tracking)
  - Tracks that guidance was provided
- **Output**: `DELTA: +X Knowledge, UNCERTAINTY: -Y`

## 13 Epistemic Vectors

### Tier 0: Foundation
- **engagement**: Level of engagement with the task
- **know**: What you know
- **do**: What you can do
- **context**: Contextual understanding

### Tier 1: Comprehension
- **clarity**: How clear the understanding is
- **coherence**: How coherent the knowledge is
- **signal**: Signal-to-noise ratio
- **density**: Information density

### Tier 2: Execution
- **state**: Current state of execution
- **change**: Rate of change
- **completion**: Completion level
- **impact**: Expected/actual impact

### Meta
- **uncertainty**: Overall uncertainty level

```sql

```

### Get Reflexes by Phase
```sql
SELECT phase, COUNT(*) as count FROM reflexes GROUP BY phase;
```

### Get Recent Findings
```sql
SELECT finding, impact, datetime(created_timestamp, 'unixepoch') as created
FROM project_findings 
ORDER BY created_timestamp DESC 
LIMIT 10;
```

### Get Recent Unknowns
```sql
SELECT unknown, datetime(created_timestamp, 'unixepoch') as created
FROM project_unknowns 
ORDER BY created_timestamp DESC 
LIMIT 10;
```

### Get Reflexes for Session
```sql
SELECT phase, timestamp, reasoning 
FROM reflexes 
WHERE session_id = 'SESSION_ID' 
ORDER BY timestamp DESC;
```
