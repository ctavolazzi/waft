404 Prompt Configurator - Test + Teaching Page

Purpose: teach the capability and let you test the full route-to-prompt flow before wiring into endpoints.

How It Works

1. Enter route 2. Check existence 3. Auto-fill context 4. Generate prompt 5. Copy to LLM

Live Playground (Real 404 Pattern)

404 - Not Found We couldn't find this route. Below this message should be a preconfigured, copy-first prompt block. Advanced controls stay below as optional adjustments.
No route check yet.

Example CLI Usage

PYENV_VERSION=3.14.3 python scripts/site_prompt_configurator.py --endpoint "/missing/route" --goal "Explain current status then provide deep drill-down"
