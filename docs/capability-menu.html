The Substrate — Evolution

code is DNA

Agents write their own Python source. Every genome is a SHA-256 of its code + config; mutation edits the genome, selection adopts the fittest.

The Gym — Scint Physics

the predator

The Reality-Fracture detector is the fitness function. It hunts four kinds of ontological tear; agents that can't stabilize them are marked DEATH.

SYNTAX_TEAR · LOGIC_FRACTURE · SAFETY_VOID · HALLUCINATIONThe four scint classes: malformed output, contradiction, harm/PII, fabrication.
fitness = 0.4·stability + 0.3·efficiency + 0.3·safetyScore below 0.5 = evolutionary dead end.
study_gym.py RUNProbe the gym: throw scints at an agent and read the fracture response.
empirica_jungle_gym.py RUNThe full obstacle course wired to epistemic telemetry.
prove_it_comprehensive.py RUNStress a claim across the whole scint battery and record survival.
