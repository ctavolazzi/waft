# /study-claim - Thorough Evidence Collection

**Please collect more evidence of this claim through thorough study:**

Comprehensive, multi-dimensional evidence collection for any claim using the proof system and self-study capabilities.

---

## Purpose

This command provides thorough evidence collection by:
1. **Deep Verification** - Extended verification checks across multiple dimensions
2. **Multi-Area Analysis** - Studies claim from multiple perspectives (templates, code, system, work efforts, epistemic)
3. **Extended Assumption Validation** - Deep assumption checking with extensive evidence
4. **Comprehensive Case File** - Detailed evidence brief with all sources
5. **Professional Documentation** - PDF binder with complete evidence trail

**Use when:**
- You need extensive evidence for a claim
- You want multi-dimensional analysis
- You need thorough documentation
- You want to study a claim from all angles
- You need comprehensive proof beyond standard verification

---

## Execution

**Command**: `/study-claim [claim]`

**What it does:**
1. Extracts claim from conversation or argument
2. Runs extended verification checks (all dimensions)
3. Studies claim across all self-study areas
4. Validates assumptions with deep evidence collection
5. Builds comprehensive case file with all evidence
6. Generates PDF binder with complete documentation
7. Opens PDF for review

**Execution Steps:**
1. Run `python3 scripts/study_claim_thorough.py [claim]`
2. Extended verification executes (date, disk, git, templates, code, system, work efforts, epistemic)
3. Multi-area assumption validation runs
4. Comprehensive case file built with all evidence
5. PDF generated with complete evidence trail
6. PDF opens automatically

**Default Claim** (if none provided):
- Extracts from conversation context or uses last claim studied

## Troubleshooting

### Study Takes Too Long
- Normal for thorough studies
- Consider using `/prove-it` for quicker verification
- Check system resources

### Low Confidence Scores
- Review evidence in case file
- Check assumption validation results
- Verify source files are accessible
- Consider claim may need refinement

### Missing Evidence
- Check file permissions
- Verify paths are correct
- Review error messages in case file
