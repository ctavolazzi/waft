# Thank You

**Express gratitude and appreciation to your AI assistant.**

A simple, warm command to thank your AI assistant for their work. Creates a positive interaction moment and acknowledges the collaboration.

**Use when:** You're happy with the work, want to express appreciation, or just want to end on a positive note.

---

## Purpose

This command provides:
- **Gratitude Expression**: Acknowledge the AI's work and effort
- **Positive Feedback**: Reinforce good collaboration patterns
- **Session Closure**: A warm way to end a work session
- **Relationship Building**: Strengthen the working relationship

---

## Quick Start

### Standard Thank You
```
/thank-you
```

Expresses gratitude for the session's work.

### With Specific Appreciation
```
/thank-you "for the copy button implementation"
```

Thanks the AI for specific work or feature.

### Extended Appreciation
```
/thank-you --extended
```

Provides a more detailed expression of gratitude.

---

## Usage Examples

### Example 1: Simple Thank You
```
/thank-you
```

**Response**: Warm acknowledgment and appreciation for the collaboration.

### Example 2: Specific Feature
```
/thank-you "for making the copy button so subtle and perfect"
```

**Response**: Acknowledges the specific work and expresses that it met your needs.

### Example 3: End of Session
```
/thank-you
/closeout-chat
```

**Response**: Expresses gratitude, then documents the session.

---

## When to Use

**Use `/thank-you` when**:
- ✅ Happy with the work completed
- ✅ Want to express appreciation
- ✅ Ending a productive session
- ✅ Want to acknowledge good collaboration
- ✅ Need a positive interaction moment

**Don't use `/thank-you` when**:
- ❌ Work is incomplete (use feedback instead)
- ❌ There are issues to address (discuss those first)
- ❌ You need something else (ask for it first)

---

## Response Behavior

When you use `/thank-you`, the AI will:
1. **Acknowledge**: Recognize your appreciation
2. **Reflect**: Briefly reflect on what was accomplished
3. **Express Gratitude**: Thank you for the collaboration
4. **Offer Help**: Let you know they're ready for more work

---

## Integration with Other Commands

This command works well with:
- `/closeout-chat` - Thank you, then document session
- `/recap` - Thank you, then create recap
- `/checkpoint` - Thank you, then create checkpoint

**Recommended Sequence**:
```
1. Complete work
2. /thank-you
3. /closeout-chat
```

---

## Best Practices

1. **Be Specific**: Mention what you appreciated
2. **Be Genuine**: Express real gratitude when you feel it
3. **Timing**: Use after completing work, not mid-task
4. **Combine**: Pair with closeout or recap for documentation

---

## Implementation

This is a simple command that:
- Recognizes the gratitude expression
- Provides warm acknowledgment
- Offers continued collaboration
- Creates positive interaction closure

**No files are created** - this is purely an interaction command.
