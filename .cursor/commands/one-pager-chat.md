# /one-pager-chat - Create One-Pager from Chat

**Purpose:** Create a crystalized 2-page one-pager PDF from the current chat session

**Usage:** `/one-pager-chat`

**Script:** `scripts/create_chat_one_pager.py`

---

## Overview

Creates a perfect 2-page printable document summarizing the current chat session. Perfect for crystallizing conversation knowledge into physical form for your binder constellation.

---

## What It Does

1. **Extracts Key Information** from the chat session
2. **Summarizes Topics** discussed
3. **Documents Tools Created** during the session
4. **Includes Usage Examples** for reference
5. **Generates 2-Page PDF** ready for printing

---

## Output

Saved to: `_work_efforts/one_pagers/chat_session_[date]_[time].pdf`

Format:
- **2 pages exactly** (front and back of one sheet)
- **Printer-friendly** (black and white)
- **Professional formatting** (field guide style)
- **Ready for binder** (standard letter size)
