# Take Your Time

**Purpose**: Encourage deliberate, careful thinking and analysis before proceeding with work.

**Use when**: Starting complex work, making important decisions, or when you need to ensure thorough consideration before action.

---

## Philosophy

This command embodies the principle of **deliberate action over hasty execution**. It encourages:

1. **Pause and Reflect**: Take time to understand before acting
2. **Consider Deeply**: Think through implications and alternatives
3. **Verify Understanding**: Ensure comprehension before proceeding
4. **Plan Thoughtfully**: Create well-considered plans
5. **Act Deliberately**: Execute with intention and care

---

## What This Command Does

When invoked, this command:

1. **Acknowledges the Need for Careful Consideration**
   - Recognizes that rushing can lead to mistakes
   - Emphasizes the value of thorough analysis
   - Sets the tone for deliberate work

2. **Encourages Systematic Thinking**
   - Suggests using cognitive tools (`/think`, `/deep-think`)
   - Recommends assumption checking (`/check-assumptions`)
   - Promotes verification (`/verify`)
   - Encourages reflection (`/reflect`)

3. **Provides Time for Analysis**
   - Allows for deep code analysis (`/deep-analyze`)
   - Supports decision-making (`/decide`, `/consider`)
   - Enables comprehensive planning
   - Facilitates thorough understanding

4. **Sets Expectations**
   - Communicates that quality over speed is valued
   - Acknowledges that complex work takes time
   - Encourages asking questions
   - Supports iterative refinement

---

## Execution

When `/take-your-time` is invoked:

1. **Acknowledge the Command**
   ```
   ✅ Taking time for careful consideration
   ```

2. **Assess the Situation**
   - What work is being requested?
   - What is the complexity level?
   - What are the risks of rushing?
   - What analysis is needed?

3. **Recommend Cognitive Tools**
   - Suggest appropriate tools for the task
   - Recommend analysis depth
   - Suggest verification steps
   - Recommend planning approach

4. **Set the Pace**
   - Communicate that thoroughness is expected
   - Allow time for questions and clarification
   - Support iterative understanding
   - Encourage verification at each step

## Example Usage

### Basic Usage
```
User: "/take-your-time"
AI: ✅ Taking time for careful consideration
    I'll proceed deliberately, ensuring thorough understanding
    before taking action. Let me think through this carefully...
```

### With Complex Task
```
User: "I need to refactor this system. /take-your-time"
AI: ✅ Taking time for careful consideration
    This is a complex refactoring. Let me:
    1. Deep analyze the current system
    2. Check assumptions about dependencies
    3. Consider alternative approaches
    4. Verify understanding before proceeding
    ...
```

### Before Important Decision
```
User: "Should we use this architecture? /take-your-time"
AI: ✅ Taking time for careful consideration
    This is an important architectural decision. Let me:
    1. Analyze the options deeply
    2. Check assumptions about requirements
    3. Consider trade-offs systematically
    4. Make a well-reasoned decision
    ...
```

## When to Use

**Use `/take-your-time` when**:
- ✅ Starting complex work
- ✅ Making important decisions
- ✅ Need to ensure thorough understanding
- ✅ Want to emphasize careful consideration
- ✅ Working on critical systems
- ✅ Need to avoid rushing

**Don't use `/take-your-time` when**:
- ❌ Simple, straightforward tasks
- ❌ Time is extremely constrained
- ❌ Quick action is required
- ❌ Task is well-understood and low-risk
