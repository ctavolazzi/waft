# Consult The Oracle

**Consult TheOracle for epistemic insights and guidance.**

Alias for `/oracle`.

**Source of truth:** `.cursor/commands/oracle.md`

---

## Usage

```
/consult-the-oracle
```

```
/consult-the-oracle "How should we proceed with desktop app architecture?"
```

## Execution

This command calls `waft oracle` internally to consult TheOracle system.

---

## Guarantee

The alias intentionally delegates all behavior to `/oracle` so there is only one canonical Oracle spec to maintain.
