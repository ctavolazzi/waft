## Description

Comprehensive execution workflow - a complete, thorough sequence that executes a full project cycle from orientation through completion. Named after the decisive command, this procedure ensures nothing is missed and everything is executed systematically.

## Use When

- Starting a new project or major feature
- Need comprehensive, systematic execution
- Want to ensure complete workflow coverage
- Need to execute a full development cycle
- Want thorough documentation and verification

## Prerequisites

- Project repository initialized
- Git configured
- Basic project structure exists
- Access to MCP servers (work-efforts, docs-maintainer, etc.)

## Steps

### Phase 1: Orientation & Context Gathering
1. Execute `/spin-up` - Quick project overview and status check
2. Execute `/orient` - Complete project orientation and startup workflow
3. Execute `/phase1` - Gather all project data, create interactive dashboard
4. Review current state and identify objectives

### Phase 2: Analysis & Planning
5. Execute `/consider` - Analyze situation, present options with recommendations
6. Execute `/analyze` - Analyze Phase 1 data, generate insights and action plans
7. Execute `/explore` - Deep codebase exploration and analysis
8. Execute `/decide` - Run decision matrix calculations for path forward

### Phase 3: Execution & Verification
9. Execute `/execute` - Gather context, then execute the planned work
10. Execute `/verify` - Verify project state with traceable evidence
11. Execute `/checkpoint` - Document current state, progress, todos

### Phase 4: Reflection & Documentation
12. Execute `/reflect` - Write reflective journal entries
13. Execute `/recap` - Create conversation recap and session summary
14. Execute `/proceed` - Verify context and assumptions before continuing

### Phase 5: Completion & Handoff
15. Execute `/checkout` - Run cleanup, documentation, summary tasks
16. Update work efforts with progress
17. Commit changes with comprehensive messages
18. Generate final summary and next steps

## Expected Output

After completing Order 66, you will have:
- Complete project orientation and understanding
- Comprehensive analysis and insights
- Clear decision on path forward
- Executed work with verification
- Full documentation (journal, recap, checkpoint)
- Clean repository state
- Updated work efforts
- Clear next steps

## Notes

- This is a comprehensive workflow - allow adequate time
- Each phase builds on the previous
- Documentation is created throughout
- Verification ensures quality at each step
- Final checkout ensures clean handoff
