# Procedure: Comprehensive Orchestration

**Shortcode**: ORC-001  
**Category**: Orchestration  
**Created**: 2026-01-10  
**Updated**: 2026-01-10  
**Status**: Active  
**Aliases**: `/orchestrate`

---

## Description

Complete orchestration workflow that combines orientation, repository analysis, visualization, goal analysis, checkpoint creation, systematic data gathering, hypothesis formation, verification, reflection, conversation recap, and strategic decision-making.

---

## Use When

- Starting a new investigation or feature
- Need systematic understanding
- Want to form and verify hypotheses
- Need comprehensive workflow
- Starting significant new work

---

## Prerequisites

- Project is a git repository
- Working directory is project root
- MCP servers available
- Waft framework initialized (if applicable)

---

## Steps

### Phase 1: Orientation
**Execute**: `/spin-up`

**Output**: Environment status, git status, active work, recent history

---

### Phase 2: Repository Analysis
**Execute**: `/consider`

**Output**: Situation analysis, options, recommendations

---

### Phase 3: Visual State Assessment
**Execute**: `/visualize`

**Output**: Interactive HTML dashboard

---

### Phase 4: Goal Analysis
**Execute**: `/analyze`

**Output**: Health analysis, issues, opportunities, insights, action plan

---

### Phase 5: Checkpoint Creation
**Execute**: `/checkpoint`

**Output**: Checkpoint file, devlog updated

---

### Phase 6: Data Gathering & Probe Execution
**Execute**: `/execute` with probe instructions

**Probes**:
1. Structural probes (project structure, architecture, dependencies, patterns)
2. Functional probes (features, APIs, integrations, testing)
3. Data probes (git history, work efforts, documentation, configuration)
4. System probes (environment, dependencies, build, tests, performance)

**Output**: Comprehensive data collection, evidence gathered

---

### Phase 7: Hypothesis Formation
**Actions**:
1. Review probe findings
2. Formulate testable hypotheses
3. Document hypothesis structure
4. Save to `_pyrite/hypothesis/`

**Output**: Hypothesis document with evidence and verification plan

---

### Phase 8: Hypothesis Verification
**Execute**: `/verify`

**Output**: Verification traces, evidence documentation, confidence assessment

---

### Phase 9: Reflection
**Execute**: `/reflect`

**Output**: Journal entry with insights and learnings

---

### Phase 10: Conversation Recap
**Execute**: `/recap`

**Output**: Complete conversation summary

---

### Phase 11: Context Verification
**Execute**: `/proceed`

**Output**: Verified understanding, assumptions checked

---

### Phase 12: Strategic Decision-Making
**Execute**: `/decide`

**Output**: Decision matrix, recommendations, next steps

---

## Expected Output

After completion:
- ✅ Complete orientation and understanding
- ✅ Visual dashboard created
- ✅ Analysis report generated
- ✅ Hypothesis formed and verified
- ✅ Reflection and recap complete
- ✅ Strategic decisions made
- ✅ All documentation created
