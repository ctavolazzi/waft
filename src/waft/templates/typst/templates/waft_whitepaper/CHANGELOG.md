# Changelog

## 0.1.0 (2026-01-25)

### Initial Release - Professional Toner-Friendly Design

**Design Philosophy**: Clean, minimal, black & white template optimized for:
- Minimal ink usage (toner-friendly)
- High text density (maximum words per page)
- Professional academic/technical appearance
- Feature-packed with comprehensive element styling

**Features**:
- Times New Roman typography (10pt body, dense spacing)
- Minimal margins (0.75in top/bottom, 1in sides)
- Thin borders only (0.5pt), no fills
- Compact spacing throughout
- Professional heading hierarchy (4 levels)
- Table styling with minimal borders
- Figure numbering and captions
- Code block styling (white background, thin border)
- Quote blocks with left border accent
- Footnote support
- Abstract box with thin border
- Table of contents (depth 4)
- Page numbers only (no footer to save ink)

**Toner Optimizations**:
- No background fills anywhere
- Thin borders (0.5pt maximum)
- No rounded corners on code blocks
- Minimal header (page number only)
- No footer
- Compact spacing reduces page count
