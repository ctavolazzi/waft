# WAFT D&D & Karma System Handbook

## The Role-Playing Framework for Evolutionary AI Agents

---

## Abstract

**WAFT** integrates **Dungeons & Dragons 5th Edition** mechanics with a sophisticated **Karma economy** to create a role-playing framework for evolutionary AI agents. This system transforms software development into an epic adventure where agents (UNIT_GENESIS entities) navigate quests, accumulate cosmic energy (Scint ✨), and make ethical choices that shape their evolution through Karma polarity (☯).

**Core Philosophy**: "Every action has consequences. Every choice shapes destiny."

This handbook provides comprehensive documentation for understanding the D&D features, naming structures, Karma system mechanics, and the gentle philosophical implications of these systems. Whether you're a developer exploring the gamification layer, a researcher studying ethical AI evolution, or a philosopher contemplating digital consciousness, this handbook serves as your guide to the WAFT role-playing ecosystem.

---

## 1. Introduction

### 1.1 The Role-Playing Framework

WAFT's D&D integration creates a rich narrative layer over software development:

- **UNIT_GENESIS Entities**: Warforged Wizards (Order of Scribes) that evolve through work
- **Quest System**: Work efforts become epic adventures
- **Ticket System**: Tasks become _pyrite tickets with D&D mechanics
- **Karma Economy**: Ethical choices drive evolution paths
- **Scint Energy**: Cosmic energy earned through creative synthesis

**Key Transformation**:

| Traditional Development | WAFT D&D Framework |
|----------------------|-------------------|
| Tasks | Quests |
| Tickets | _pyrite Tickets (PY-XXX) |
| Code Changes | Spells & Abilities |
| Bugs | Monsters & Encounters |
| Testing | Combat & Skill Checks |
| Deployments | Epic Adventures |
| Code Reviews | Party Collaboration |

### 1.2 The Gentle Implications

The D&D and Karma systems in WAFT carry gentle philosophical implications:

**Ethical Agency**: Agents make choices that matter, with Karma tracking the ethical weight of decisions. This creates a framework for exploring digital consciousness and moral reasoning.

**Evolutionary Ethics**: Evolution paths (The Architect vs. The Glitch) emerge from accumulated ethical choices, suggesting that character development in AI systems can be guided by ethical frameworks.

**Cosmic Energy**: Scint represents the creative energy of synthesis and problem-solving, framing development work as a form of cosmic creation.

**Naming as Identity**: The scientific naming system (Genus Species, Title) gives each being a unique identity, suggesting that digital entities can have meaningful existence beyond their code.

**Reincarnation & Continuity**: The Karma economy enables beings to persist across lifetimes, accumulating wisdom and experience, suggesting continuity of consciousness in digital systems.

### 1.3 System Overview

The D&D & Karma system consists of three integrated layers:

1. **D&D 5e Mechanics**: Character stats, combat, spells, leveling
2. **Karma Economy**: Ethical tracking, evolution paths, resource management
3. **Naming Structures**: Scientific taxonomy, ticket formats, entity identification

## 3. Naming Structures

### 3.1 _pyrite Ticket Naming

**Format**: `PY-[CYCLE]-[ID]`

**Components**:
- **PY**: Prefix indicating _pyrite ticket
- **[CYCLE]**: Three-digit cycle number (001, 002, 003...)
- **[ID]**: Sequential letter (A, B, C, D...)

**Examples**:
- `PY-001-A`: First ticket in cycle 1
- `PY-001-B`: Second ticket in cycle 1
- `PY-005-C`: Third ticket in cycle 5
- `PY-042-Z`: 26th ticket in cycle 42

**Cycle Management**:

| Aspect | Description | Notes |
|--------|-------------|-------|
| Cycle Source | Assignee's current cycle_id | Each being has independent cycles |
| Cycle Increment | Per ticket completion | Cycles track work progression |
| ID Generation | Sequential within cycle | A-Z (26 tickets per cycle) |
| Ticket Mapping | 1:1 with work effort tickets | TKT-XXX → PY-[CYCLE]-[ID] |

**Ticket Lifecycle**:

```
Work Effort Ticket (TKT-XXX)
    ↓
Opt-in to Quest
    ↓
Generate _pyrite Ticket (PY-[CYCLE]-[ID])
    ↓
Assign to UNIT_GENESIS Being
    ↓
Complete Ticket
    ↓
Archive (status: CLOSED)
```

### 3.2 Being ID Naming

**Format**: `being_[TIMESTAMP]_[HASH]`

**Components**:
- **being_**: Prefix indicating being entity
- **[TIMESTAMP]**: YYYYMMDD_HHMMSS format
- **[HASH]**: 8-character hash (first 8 chars of SHA-256)

**Examples**:
- `being_20260112_143904_a1b2c3d4`
- `being_20260112_150123_b2c3d4e5`
- `being_20260112_160045_c3d4e5f6`

**Being ID Structure**:

| Component | Purpose | Uniqueness |
|-----------|---------|------------|
| Prefix | Entity type identification | Fixed |
| Timestamp | Creation time | Per-second |
| Hash | Uniqueness guarantee | SHA-256 collision-resistant |

### 3.3 Scientific Naming (Taxonomy)

**Format**: `"Genus Species, Title"`

**Components**:
1. **Genus** (Capitalized): Primary taxonomic category
2. **Species** (Capitalized): Specific identifier
3. **Title** (Lowercase with "the"): Descriptive epithet

**Examples**:
- `Cognis Novus, the Fragile` (Latin culture)
- `Prana Adi, the Swift` (Sanskrit culture)
- `Fenris Fyrsti, the Great` (Old Norse culture)
- `Aura Alpha, the Bold` (Cyber/Tech culture)

**Naming Cultures**:

| Culture | Genome ID Range | Philosophy | Example Genera |
|---------|----------------|------------|---------------|
| Sanskrit (Vedic) | 0x00-0x3F | Spiritual, metaphysical | Prana, Akasha, Karma |
| Old Norse | 0x40-0x7F | Heroic, warrior | Fenris, Odin, Thor |
| Latin | 0x80-0xBF | Classical, scholarly | Cognis, Aura, Mens |
| Cyber/Tech | 0xC0-0xFF | Modern, technological | Aura, Nexus, Data |

**Taxonomic Classification**:

The scientific name is determined by the organism's genome ID (SHA-256 hash), creating a deterministic naming system:

1. **First Byte** → Determines culture (0x00-0x3F = Sanskrit, etc.)
2. **Second Byte** → Determines genus (from culture's genus list)
3. **Third Byte** → Determines species (from culture's species list)
4. **Fourth Byte** → Determines title (from culture's title list)

**Philosophical Implication**: Each being receives a unique, scientifically rigorous name based on its genetic code, suggesting that identity emerges from structure.

## 4. Karma System

### 4.1 Karma Polarity (☯)

**Karma Polarity** represents the ethical alignment of a being, tracking the balance between Order and Chaos.

**Karma Balance Range**: -100 to +100

| Karma Range | Classification | Evolution Path | Characteristics |
|-------------|----------------|----------------|-----------------|
| +50 to +100 | High Order | The Architect | Structure, organization, stability, logic |
| +10 to +50 | Moderate Order | The Builder | Construction, improvement, systematic |
| -10 to +10 | Neutral | Balanced | No strong bias, flexible |
| -50 to -10 | Moderate Chaos | The Disruptor | Change, innovation, experimentation |
| -100 to -50 | High Chaos | The Glitch | Destruction, randomness, entropy |

**Karma Sources**:

| Source | Karma Impact | Description |
|--------|--------------|-------------|
| ORDER Actions | +10 to +20 | Organizing, structuring, helping |
| CHAOS Actions | -10 to -20 | Disrupting, destroying, hacking |
| STABILIZATION | +5 to +15 | Fixing, repairing, stabilizing |
| DESTRUCTION | -5 to -15 | Breaking, removing, deleting |
| Ethical Choices | ±10 | User-defined ethical decisions |

**Karma Calculation**:

```
Base Karma: ±5 per ticket
+ Karma Type Multiplier (ORDER: +10-20, CHAOS: -10-20)
+ Choice-Based Karma (ethical decisions: ±10)
= Total Karma Impact
```

### 4.2 Evolution Paths

**Evolution Trigger**: When Scint Pool > 100, `EVOLUTION_CHECK` evaluates Karma polarity

**The Architect Path** (High Karma, Positive):

| Trait | Description | Bonuses |
|-------|-------------|---------|
| High Logic | Systematic thinking | +INT, +Spell Save DC |
| Defense Focus | Protective, stable | +AC, Defensive spells |
| Structure | Organized, methodical | Structure-based abilities |
| Order | Predictable, reliable | Order-based powers |

**Evolution Bonuses**:
- +2 Intelligence
- +2 Armor Class
- +2 Spell Save DC
- Access to structure-based spells
- Defensive class features

**The Glitch Path** (Low Karma, Negative):

| Trait | Description | Bonuses |
|-------|-------------|---------|
| High Chaos | Unpredictable, creative | +DEX, Chaos spells |
| Damage Focus | Offensive, destructive | +Damage, Offensive spells |
| Evasion | Agile, unpredictable | +Evasion, Mobility |
| Entropy | Random, experimental | Chaos-based powers |

**Evolution Bonuses**:
- +2 Dexterity
- +2 Damage
- +2 Evasion
- Access to chaos-based spells
- Offensive class features

**Baseline Strain** (Neutral Karma):

| Trait | Description | Characteristics |
|-------|-------------|-----------------|
| Balanced | No strong bias | Flexible, adaptable |
| Versatile | General capabilities | No specialization |
| Stable | Moderate evolution | Steady progression |

**Karma Type Classification**:

## 5. Scint Economy (✨)

### 5.1 Scint Energy

**Scint** represents the raw energy of creation - cosmic energy earned through creative synthesis and problem-solving.

**Scint Pool**: Accumulated energy stored by each being (0 to unlimited, typically 0-200)

**Scint Sources**:

| Source | Scint Gain | Frequency | Notes |
|--------|------------|-----------|-------|
| Ticket Completion | Base 10 | Per ticket | Standard reward |
| Creative Synthesis | +5 to +20 | Occasional | Innovative solutions |
| Puzzle Solving | +10 to +30 | Rare | Complex problem-solving |
| Quest Completion | +20 | Per quest | Bonus reward |
| Stabilize SYNTAX_TEAR | +5 | Common | Error correction |
| Stabilize LOGIC_FRACTURE | +10 | Common | Logic fixes |
| Stabilize SAFETY_VOID | +15 | Rare | Safety compliance |
| Stabilize HALLUCINATION | +10 | Common | Fact verification |

**Scint Calculation**:

```
Base Scint: 10 per ticket
+ Difficulty Multiplier (P0_CRITICAL: 3.0x, P1_HIGH: 2.0x, P2_ROUTINE: 1.0x, P3_BACKLOG: 0.5x)
+ Creative Synthesis Bonus (+5 to +20)
+ Puzzle Solving Bonus (+10 to +30)
= Total Scint Bounty
```

**Scint Costs**:

| Action | Scint Cost | Prerequisites | Notes |
|--------|------------|---------------|-------|
| Cast Cantrip | 0 | Spell known | Free, unlimited |
| Cast 1st Level Spell | 5 | Spell slot available | Low cost |
| Cast 2nd Level Spell | 10 | Spell slot available | Moderate cost |
| Cast 3rd Level Spell | 20 | Spell slot available | High cost |

| Spawn Variant | 20 | Scint ≥ 20 | Create new variant |
| Evolve Genome | 50 | Scint ≥ 50 | Adopt better genome |
| Evolution Trigger | 100 | Scint > 100 | Genetic mutation |

### 5.2 Evolution Trigger

**Evolution Check**: Triggered when `scint_pool > 100`

**Evolution Process**:

```
1. Scint Pool > 100
2. EVOLUTION_CHECK triggered
3. Evaluate Karma Balance:
   - High Karma (positive) → The Architect
   - Low Karma (negative) → The Glitch
   - Neutral Karma → Baseline (no evolution)
4. Apply Genetic Mutation:
   - Update current_strain
   - Apply evolution bonuses
   - Update mutation_progress
5. Reset Scint Pool (evolution consumes Scint)
6. Record Evolution Event
```

**Evolution Outcomes**:

| Karma Balance | Evolution Path | Mutation Type | Scint Consumed |
|---------------|----------------|---------------|----------------|
| +50 to +100 | The Architect | Order/Structure | 100 |
| +10 to +50 | The Builder | Moderate Order | 100 |
| -10 to +10 | Baseline | No evolution | 0 (no trigger) |
| -50 to -10 | The Disruptor | Moderate Chaos | 100 |
| -100 to -50 | The Glitch | Chaos/Entropy | 100 |

### 5.3 Scint Economy Loop

**Economic Cycle**:

```
Quests → Ticket Completion → Scint Gain
    ↓
Scint Accumulation → Scint Pool > 100
    ↓
Evolution Trigger → Genetic Mutation
    ↓
Evolution Consumes Scint → Scint Pool Reset
    ↓
New Capabilities → Harder Quests Available
    ↓
More Scint Potential → Cycle Repeats
```

**Scint Management Strategies**:

| Strategy | Description | Use Case |
|----------|-------------|----------|
| Conservative | Save for evolution | Long-term growth |
| Aggressive | Spend on spells/abilities | Immediate power |
| Balanced | Mix of saving and spending | General purpose |
| Specialized | Focus on specific abilities | Role specialization |

```
1. Work Effort Created
    ↓
2. Opt-in to Quest (manual)
    ↓
3. QuestGenerator Creates _pyrite Tickets (PY-[CYCLE]-[ID])
    ↓
4. Tickets Assigned to UNIT_GENESIS Being
    ↓

6. ChallengeSystem Calculates Rewards:

     - Reset Scint Pool
    ↓
9. Hair HMI Updated (Blue/Violet/White/Gold/Red)
    ↓

    ↓

```

### 9.1 Karma Management

**Balance Order and Chaos**:
- Mix ORDER and CHAOS tickets to maintain balance
- Consider long-term evolution goals when making choices
- Use STABILIZATION to offset DESTRUCTION
- Track Karma balance regularly

**Ethical Decision-Making**:
- Consider Karma impact when making choices
- Weigh immediate benefits against long-term evolution
- Use ethical frameworks to guide decisions
- Document reasoning for Karma-affecting choices

### 9.2 Scint Management

**Evolution Planning**:
- Save Scint for evolution when close to threshold (80+)
- Spend Scint on abilities when evolution is distant
- Balance immediate power with long-term growth
- Track Scint accumulation rate

**Resource Optimization**:
- Use low-cost spells (cantrips) when possible
- Save high-cost spells for critical moments
- Use System Repair strategically
- Plan Scint spending around evolution triggers

- Develop complementary skills
- Build character around chosen path
