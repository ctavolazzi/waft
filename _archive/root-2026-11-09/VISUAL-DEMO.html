What You'll Experience

When you run the visualizer, you'll see:

🎨 Colorful particle beings moving across a dark canvas using boids algorithm (separation, alignment, cohesion)

🏗️ Building icons (🌾🏠💧🏭) that you can drag and drop onto the canvas to create your village

👷 Worker assignment interface where you select beings based on their genetic traits to work in buildings

📊 Live resource panels showing food, water, wood, stone changing in real-time as buildings produce/consume

🧬 Population statistics tracking fitness, age, genetic diversity, births, deaths across generations

⚡ Simulation controls to start/pause/speed up the evolution and watch population dynamics unfold

🎓 Tutorial system that guides you through building your first village step-by-step
