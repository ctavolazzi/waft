## Project Overview

**WAFT** is a Python framework for directed evolution of self-modifying AI agents. Core concept: "Don't just build agents. Breed them."

### Core Pillars

1. **The Substrate**: Agents that write their own Python source code (DNA)
   - Agents can spawn variants with mutations
   - Evolve by hot-swapping their own code/config
   - Reproduce by creating children with genetic modifications

2. **The Physics**: Scint System (Ontological Error Detection) as fitness function
   - Reality Fracture Detection System tests agents
   - Agents must stabilize Scints to survive
   - Fitness measured by stability, efficiency, and safety scores

3. **The Flight Recorder**: Telemetry system for phylogenetic trees
   - Tracks agent lineage and evolution
   - Records genetic modifications
