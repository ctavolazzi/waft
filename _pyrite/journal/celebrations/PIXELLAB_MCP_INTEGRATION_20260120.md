## 💡 What We Learned

- **PixelLab MCP works**: Remote API integration is functional
- **Characters take 2-3 min**: Map objects are faster (~30-90s)
- **Base64 embedding**: Clean way to include images in HTML
- **image-rendering: pixelated**: CSS property for crisp pixel art
- **Rate limits exist**: Can't spam too many requests
