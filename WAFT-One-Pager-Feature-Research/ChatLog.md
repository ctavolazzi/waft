   - Integration plan with OnePager

### How It Works

**Components as Digital Organisms**:
- Each component type (sections, headers, lists, paragraphs, code blocks) has a genome
- Genome ID = SHA-256 hash of component configuration
- Components track: content density, space efficiency, readability, usage frequency

**Evolutionary Process**:
1. **SPAWN**: Components spawn variants with mutations (font size, margins, spacing, style)
2. **GYM_EVAL**: Variants evaluated on fitness (content density + efficiency + readability)
3. **MUTATE**: Best variant hot-swaps to replace current component
4. **SURVIVAL/DEATH**: Components with fitness >= 0.5 survive, < 0.5 die

**Genetic Ancestry**:
- Complete lineage tracking (parent_id, generation, lineage_path)
- Flight recorder events for all evolutionary actions
- Family tree reconstruction for analysis

- Components evolve to maximize content density
- Better space utilization (optimized margins, spacing, fonts)
- Components adapt to usage patterns
- Maintained readability
- Complete scientific tracking for research
