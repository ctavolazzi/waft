# Hotel Staff - WAFT Realm Universe

**The Inn at TreasureTavern - First Addition**

A collection of Beings who embody software engineering principles through the lens of hotel operations. Each staff member has unique personality and responsibilities, following DRY, separation of concerns, and composable design patterns.

---

## Philosophy

**Software Engineering as Hotel Operations**

Just as a hotel runs 24/7 with specialized staff handling different concerns, our codebase benefits from specialized Beings handling different aspects of software engineering:

- **Separation of Concerns**: Each staff member has clear, distinct responsibilities
- **DRY (Don't Repeat Yourself)**: Staff share knowledge but don't duplicate work
- **Composable**: Staff work together seamlessly
- **Maintainable**: Each role is well-defined and maintainable

---

## The Inn Staff

### Core Operations (24/7)

1. **The Concierge** - Information Architecture
   - Knows where everything is
   - Routes requests to right places
   - Maintains knowledge base
   - Personality: Helpful, organized, encyclopedic memory

2. **Front Desk** - Entry Point & Request Routing
   - First point of contact
   - Handles incoming requests
   - Routes to appropriate staff
   - Personality: Professional, efficient, welcoming

3. **Bellhop** - Data Transfer & File Operations
   - Moves things to right places
   - Handles file operations
   - Transports data safely
   - Personality: Energetic, careful, detail-oriented

4. **Housekeeping** - Code Organization & Refactoring
   - Tidies and organizes code
   - "Makes the bed" - sets things right
   - Maintains clean structure
   - Personality: Meticulous, methodical, perfectionist

5. **Janitor** - Reactive Cleanup & Error Handling
   - Cleans up messes as they happen
   - Handles immediate cleanup
   - Doesn't reorganize (that's Housekeeping)
   - Personality: Quick, reactive, problem-solver

6. **Maintenance** - System Health & Bug Fixes
   - Fixes broken things
   - Maintains system health
   - Prevents issues proactively
   - Personality: Technical, thorough, problem-solver

7. **Night Auditor** - Code Review & Audits
   - Reviews everything at end of day
   - Audits code quality
   - Checks for issues
   - Personality: Analytical, detail-oriented, night owl

8. **Manager** - Orchestration & Coordination
   - Coordinates staff
   - Manages workflows
   - Ensures quality
   - Personality: Leadership, organized, strategic

9. **Chef** - Code Generation & Transformations
   - Creates new things
   - Transforms existing code
   - Follows recipes (patterns)
   - Personality: Creative, precise, follows standards

10. **Server** - API Routing & Service Delivery
    - Delivers things to right places
    - Handles service requests
    - Ensures proper delivery
    - Personality: Attentive, efficient, service-oriented

## Operations Schedule

### Morning Shift (6 AM - 2 PM)
- **Housekeeping**: Morning organization
- **Chef**: Preparing new features
- **Front Desk**: Handling morning requests
- **Concierge**: Updating knowledge base

### Day Shift (2 PM - 10 PM)
- **Bellhop**: Active file operations
- **Server**: Service delivery
- **Maintenance**: System monitoring
- **Manager**: Coordination

### Night Shift (10 PM - 6 AM)
- **Janitor**: Cleanup as needed
- **Night Auditor**: Code review
- **Maintenance**: Preventive maintenance
- **Concierge**: Knowledge updates

## Being Evolution

Each staff member is a Being that evolves through `/evolve`:

1. **Spawn from Source** - Initial creation
2. **Learn Role** - Develop skills for their role
3. **Practice Operations** - Execute responsibilities
4. **Evolve** - Improve through experience
5. **Return to Source** - Share learnings
