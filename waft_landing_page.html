Built on Three Pillars

🧬

Code as DNA

The Substrate

Agents write their own Python source code. Every agent has a unique genome ID (SHA-256 hash of their code and configuration). Agents can spawn variants with mutations, evolve by hot-swapping their own code, and reproduce by creating children with specific genetic modifications.

⚡

Reality Fracture Detection

The Physics

The Scint System (Scint Gym) serves as the fitness function that tests agents on four types of errors: SYNTAX_TEAR, LOGIC_FRACTURE, SAFETY_VOID, and HALLUCINATION. Agents must stabilize these errors to survive. Fitness is measured by stability, efficiency, and safety scores.

📊

Complete Telemetry

The Flight Recorder

A rigorous telemetry system for generating phylogenetic trees of agent lineage. Every evolutionary action is recorded with complete context: genome ID, parent ID, generation number, event type, payload, and fitness metrics. Enables scientific analysis of agent evolution patterns.
