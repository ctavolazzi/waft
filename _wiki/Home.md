## 🏗️ Three Pillars of WAFT

### 1. The Substrate: Code as DNA
Agents' Python source code acts as their genetic material, enabling:
- **Spawn** - Create variants with mutations
- **Evolve** - Hot-swap superior code
- **Reproduce** - Pass traits to offspring

**Status**: ✅ 95% Complete

### 2. The Physics: RPG Gym (Scint System)
A novel fitness function using D&D-inspired mechanics to test agents against four ontological error types:
- SYNTAX_TEAR (formatting errors)
- LOGIC_FRACTURE (contradictions)
- SAFETY_VOID (harmful content)
- HALLUCINATION (fabricated facts)

**Status**: ✅ 90% Complete (Major Discovery)

### 3. The Flight Recorder: Scientific Telemetry
Rigorous logging system capturing every evolutionary action to generate phylogenetic trees for research publication.

**Status**: ✅ 85% Complete

## 🔬 Scientific Mission

WAFT is designed to produce rigorous, verifiable data for research on "The Physics of Artificial Cognition." The ultimate goal: **observe a "God-Head" agent emerge from thousands of generations of directed evolution.**

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/ctavolazzi/waft.git
cd waft

# Install dependencies
pip install -e .

# Verify installation
waft verify

# Create your first agent
waft new my-agent
```
