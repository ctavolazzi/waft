## Objective
Create a comprehensive "Projects" feature that allows users to create and manage long-term projects that can be worked on incrementally over time. This feature will enable users to track progress, organize work, and chip away at large projects systematically. The system will integrate with existing WAFT infrastructure (file-based storage, CLI, work efforts) and provide a foundation for managing complex, multi-session work like the campaign book generation system.

## Key Requirements

1. **Project Creation & Management**
   - Create new projects with metadata (title, description, status, tags)
   - List, view, update, and delete projects
   - Track project status (planning, active, paused, completed, archived)

2. **Progress Tracking**
   - Track completion percentage
   - Record milestones and checkpoints
   - Log work sessions and time spent
   - Track related work efforts and tickets

3. **Incremental Work Support**
   - Support "chipping away" at projects over time
   - Session-based progress updates
   - Quick status updates
   - Progress notes and reflections

4. **Integration Points**
   - Link to work efforts (Johnny Decimal system)
   - Link to campaign book generation system
   - Integrate with CLI commands
   - Store in `_pyrite/.waft/projects/` directory

5. **CLI Interface**
   - `waft project create <name>` - Create new project
   - `waft project list` - List all projects
   - `waft project show <id>` - Show project details
   - `waft project update <id>` - Update project
   - `waft project progress <id>` - Update progress
   - `waft project status <id>` - Quick status check
