## Component Design

### 1. Reality System

**Purpose**: Spin up "realities" - simulation environments where beings can exist and learn.

**Features**:
- Create realities with specific configurations
- Spawn beings into realities
- Manage reality lifecycle
- Track reality state and outcomes
- Archive realities when complete

**Reality Types**:
- `learning_reality` - Beings learn skills
- `testing_reality` - Beings test skills
- `evolution_reality` - Beings evolve through natural selection
- `research_reality` - Beings conduct research
- `creative_reality` - Beings create new things

### 2. Beings System

**Purpose**: Entities that exist in realities, learn skills, and evolve.

**Features**:
- Beings spawn into realities
- Beings learn skills through experience
- Beings evolve through natural selection
- Beings pass memories/lessons upward
- Beings can exchange lifetimes

**Being States**:
- `spawning` - Being created
- `learning` - Being learning skills
- `evolving` - Being evolving
- `completing` - Being finishing reality
- `archived` - Being archived

### 3. Skills System

**Purpose**: What beings can learn and evolve.

**Features**:
- Skills have levels (0-100)
- Skills evolve through use
- Skills can mutate/improve
- Skills passed to offspring
- Skills contribute to fitness

**Skill Types**:
- `cognitive` - Thinking, reasoning, analysis
- `creative` - Creation, expression, innovation
- `social` - Communication, collaboration
- `technical` - Code, tools, systems
- `meta` - Learning how to learn

### 4. Memory/Lesson Passing

**Purpose**: Knowledge flows upward as lessons learned and skills gained.

**Features**:
- Extract lessons from experiences
- Package skills for upward flow
- Pass memories through ancestral chain
- Source accumulates knowledge
- Knowledge improves future realities

**Memory Types**:
- `lessons_learned` - What worked/didn't work
- `skills_gained` - New abilities
- `patterns_discovered` - Recurring patterns
- `insights` - Deep understanding
- `wisdom` - Higher-level knowledge

### 5. Lifetime Exchange

**Purpose**: Mechanism for beings to exchange lifetimes, skills, and memories.

**Features**:
- Beings can trade lifetimes
- Beings can share skills
- Beings can exchange memories
- Market-based exchange (karma as currency)
- Facilitates knowledge transfer
