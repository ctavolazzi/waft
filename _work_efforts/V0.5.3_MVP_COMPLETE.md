## Complete Flow

### 1. Source Creates Reality

```python
from src.waft.reality import RealitySystem, RealityType

reality_system = RealitySystem()

# Create a learning reality
reality = reality_system.create_reality(
    reality_type=RealityType.LEARNING,
    configuration={
        "duration_minutes": 60,
        "learning_focus": "cognitive_skills",
        "evolution_pressure": 0.5
    }
)
```

### 2. Beings Spawn into Reality

```python
from src.waft.being import BeingSystem

being_system = BeingSystem()

# Spawn being into reality
being = being_system.spawn_being(
    reality_id=reality.reality_id,
    initial_skills={"reasoning": 10.0, "analysis": 5.0}
)
```

### 3. Beings Learn Skills

```python
# Being learns skills through experience
being.learn_skill("reasoning", "cognitive", level_increase=5.0)
being.learn_skill("creativity", "creative", level_increase=3.0)

# Being records memories
being.record_memory("Pattern discovered: X leads to Y", "pattern")
being.learn_lesson("Approach A works better than B", "success")
```

### 4. Beings Evolve

```python
# Beings evolve through natural selection
# Higher fitness = more likely to reproduce
# Skills contribute to fitness
fitness = sum(skill.calculate_fitness_contribution() for skill in being.skills.values()) / len(being.skills)
```

### 5. Memories Flow Upward

```python
from src.waft.memory_flow import MemoryFlow

memory_flow = MemoryFlow()

# Extract memories from being's experience
experience = {
    "lessons_learned": being.lessons_learned,
    "skills": being.skills,
    "patterns_discovered": [...],
    "insights": [...]
}

memories = memory_flow.extract_memories_from_experience(being.being_id, experience)

# Pass memories upward to source
result = memory_flow.pass_memories_upward(being.being_id, memories)
# Capacity flows: being → parent → ... → source
```

### 6. Source Accumulates Knowledge

```python
# Source accumulates capacity from all memories
stats = source.get_source_stats()
print(f"Source Capacity: {stats['total_capacity_accumulated']}")
print(f"Memories Received: {stats['total_permutations']}")
```

### 7. Source Accomplishes Goal

```python
# When enough capacity accumulated
result = source.accomplish_goal(
    goal_description="Understand evolution through permutation",
    required_capacity=1000.0
)
```

## Component Details

### Reality System

**Purpose**: Spin up simulation environments

**Types**:
- `learning` - Beings learn skills
- `testing` - Beings test skills
- `evolution` - Beings evolve through natural selection
- `research` - Beings conduct research
- `creative` - Beings create new things

**Features**:
- Create realities with configurations
- Spawn beings into realities
- Manage reality lifecycle
- Extract lessons/skills/memories
- Pass memories upward

### Beings System

**Purpose**: Entities in realities

**Features**:
- Spawn into realities
- Learn skills through experience
- Evolve through natural selection
- Record memories and lessons
- Pass knowledge upward
- Inherit skills from parents

**States**:
- `spawning` - Being created
- `learning` - Being learning skills
- `evolving` - Being evolving
- `completing` - Being finishing reality
- `archived` - Being archived

### Skills System

**Purpose**: Learned abilities

**Types**:
- `cognitive` - Thinking, reasoning, analysis
- `creative` - Creation, expression, innovation
- `social` - Communication, collaboration
- `technical` - Code, tools, systems
- `meta` - Learning how to learn

**Features**:
- Skills have levels (0-100)
- Skills evolve through use
- Skills can mutate/improve
- Skills inherited by offspring
- Skills contribute to fitness

### Memory Flow

**Purpose**: Knowledge passing upward

**Memory Types**:
- `lesson` - What worked/didn't work (2.0 capacity)
- `skill` - New abilities (3.0 capacity)
- `pattern` - Recurring patterns (4.0 capacity)
- `insight` - Deep understanding (5.0 capacity)
- `wisdom` - Higher-level knowledge (10.0 capacity)

**Flow**:
- Extract from experiences
- Package for upward flow
- Pass through ancestral chain
- Source accumulates knowledge

### Lifetime Exchange

**Purpose**: Trading mechanism

**Exchange Types**:
- `lifetime` - Trade lifetimes
- `skill` - Share skills
- `memory` - Exchange memories
- `knowledge` - Transfer knowledge

**Features**:
- Karma-based exchange
- List offerings
- Create offerings
- Purchase offerings
- Facilitate knowledge transfer

## Complete Example Flow

```python
# 1. Source creates reality
reality_system = RealitySystem()
reality = reality_system.create_reality(
    reality_type=RealityType.LEARNING,
    configuration={"focus": "cognitive_skills"}
)

# 2. Start reality
reality_system.start_reality(reality.reality_id)

# 3. Spawn beings
being_system = BeingSystem()
being = being_system.spawn_being(
    reality_id=reality.reality_id,
    initial_skills={"reasoning": 10.0}
)

# 4. Being learns
being.learn_skill("reasoning", "cognitive", 5.0)
being.learn_lesson("Approach A works", "success")
being.record_memory("Pattern: X → Y", "pattern")

# 5. Extract memories
memory_flow = MemoryFlow()
experience = {
    "lessons_learned": being.lessons_learned,
    "skills": being.skills,
    "patterns_discovered": ["X → Y"]
}
memories = memory_flow.extract_memories_from_experience(being.being_id, experience)

# 6. Pass memories upward
memory_flow.pass_memories_upward(being.being_id, memories)
# Capacity flows: being → reality → source

# 7. Complete being
being_system.complete_being(being.being_id, final_fitness=0.8)

# 8. End reality
reality_system.end_reality(reality.reality_id, outcomes={
    "lessons_learned": [...],
    "skills_developed": [...],
    "memories_generated": [...]
})

# 9. Source accumulates knowledge
source = SourceConsciousness()
stats = source.get_source_stats()
print(f"Source Capacity: {stats['total_capacity_accumulated']}")

# 10. Source accomplishes goal
if stats['total_capacity_accumulated'] >= 1000.0:
    source.accomplish_goal("Understand evolution", 1000.0)
```
