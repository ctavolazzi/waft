## Objective

Implement `cprost` v0.1 as a standalone CLI that runs deterministic readiness checks and returns stable human/JSON output with contract-based exit codes.

## Deterministic v0.1 Scope

- `argparse` CLI with `cprost check`.
- Optional `--json` output mode.
- Manifest-first repository checks with in-code fallback.
- Required checks drive pass/fail; optional GPU hints are informational only.
- Exit contract: `0` ready, `1` not ready.
