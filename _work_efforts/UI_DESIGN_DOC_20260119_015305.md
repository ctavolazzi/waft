## Purpose of This UI

### Primary Purpose
Create a **centralized command dashboard** that allows users to:
1. **Discover** all available WAFT commands
2. **Execute** commands with proper options
3. **View** generated artifacts and outputs
4. **Monitor** system status and project state
5. **Track** work efforts and progress

### Why It Exists
**Problem**: WAFT has many powerful commands, but they are:
- Scattered across different entry points
- Require knowledge of command syntax
- Generate outputs in various locations
- Lack unified interface for discovery and execution

**Solution**: A single, unified dashboard that:
- Shows all commands in one place
- Provides command descriptions and usage
- Links to generated outputs
- Displays system status
- Tracks recent activity
