# Being Character Sheet Generator

## Overview

The Being Character Sheet Generator automatically creates D&D 5e character sheets for Beings when they are spawned. It uses a template system with placeholders and generates character sheets in multiple formats.

## Default Behavior

**When a Being is created:**
- ✅ **.txt file** is automatically generated in `_hidden/.truth/beings/{being_id}/character_sheet.txt`
- ❌ **.md file** is NOT generated (on-demand only)
- ❌ **.pdf file** is NOT generated (on-demand only)

This ensures minimal overhead - only .txt is created by default.

## On-Demand Generation

To generate .md or .pdf formats, call the functions explicitly:

```python
from src.waft.evolution.being_character_sheet_generator import (
    generate_character_sheet_md,
    generate_character_sheet_pdf
)

# Generate .md
md_path = generate_character_sheet_md(being, project_path=project_path)

# Generate .pdf
pdf_path = generate_character_sheet_pdf(being, project_path=project_path)
```

## Template System

The generator uses a template with placeholders that are filled from Being data:

**Key Placeholders:**
- `{NAME}` - Character name (from Being ID)
- `{CLASS_LEVEL}` - Class and level
- `{STR}`, `{DEX}`, `{CON}`, `{INT}`, `{WIS}`, `{CHA}` - Ability scores
- `{STR_MOD}`, `{DEX_MOD}`, etc. - Ability modifiers
- `{ACROBATICS}`, `{ATHLETICS}`, etc. - Skill modifiers
- `{AC}`, `{HP}`, `{INITIATIVE}` - Combat stats
- `{BEING_ID}`, `{REALITY_ID}` - Being metadata

## Being to Character Conversion

The generator:
1. Creates a D&D character from Being (rolls ability scores)
2. Maps Being skills to character abilities (optional enhancement)
3. Extracts personality from Being.personality
4. Uses Being memories for backstory
5. Calculates all D&D stats (modifiers, saves, skills, AC, etc.)

## Integration Points

**Automatic Generation:**
- `BeingSystem.spawn_being()` automatically calls `generate_character_sheet_txt()`
- Happens after Being is saved
- Fails silently if character sheet generation unavailable (Being still works)

**Manual Generation:**
- Call `generate_character_sheet_md()` or `generate_character_sheet_pdf()` when needed
- Can be called from any code that has access to a Being instance

## File Locations

**Default (.txt):**
- `_hidden/.truth/beings/{being_id}/character_sheet.txt`

**On-Demand (.md/.pdf):**
- `_hidden/.truth/beings/{being_id}/character_sheet.md`
- `_hidden/.truth/beings/{being_id}/character_sheet.pdf`

## Example

```python
from src.waft.being import BeingSystem
from src.waft.evolution.being_character_sheet_generator import (
    generate_character_sheet_md,
    generate_character_sheet_pdf
)

# Spawn a Being (automatically generates .txt)
being_system = BeingSystem(project_path=project_path)
being = being_system.spawn_being(
    reality_id="campaign_reality",
    initial_skills={"strength": 60.0, "dexterity": 45.0}
)

# .txt already exists at:
# _hidden/.truth/beings/{being_id}/character_sheet.txt

# Generate .md on demand
md_path = generate_character_sheet_md(being, project_path=project_path)

# Generate .pdf on demand
pdf_path = generate_character_sheet_pdf(being, project_path=project_path)
```

## Customization

The template can be customized by modifying `CHARACTER_SHEET_TEMPLATE` in `being_character_sheet_generator.py`.

Character data can be customized by:
- Providing a `DnD5eCharacter` instance to override auto-generation
- Modifying the `being_to_character_data()` function
- Adjusting `create_character_from_being()` logic

---

**Note:** The generator is designed to be lightweight - only .txt is generated by default to minimize overhead when creating many Beings.
