## Stage 1: Security Foundation (CRITICAL - Start Here)

**Duration**: 2-3 hours  
**Status**: Ready to start  
**Priority**: 🔴 CRITICAL

### Objectives
- Implement security validation functions
- Create safe file scanning utilities
- Establish security patterns before any file operations

### Tasks

#### 1.1 Security Constants & Patterns
- [ ] Define `SENSITIVE_PATTERNS` list:
  - `_hidden/`, `.env*`, `secrets/`, `*.key`, `*.pem`, `*.secret`, `.git/`, `node_modules/`
- [ ] Define `MAX_HTML_SIZE = 10 * 1024 * 1024` (10MB)
- [ ] Define `MAX_PARSING_TIME = 30` (seconds)
- [ ] Define file permission constants: `FILE_PERM = 0o600`, `DIR_PERM = 0o700`

#### 1.2 Path Validation Functions
- [ ] Implement `_is_sensitive_file(path: Path) -> bool`
  - Check against SENSITIVE_PATTERNS
  - Validate path is within project root
  - Reject symlinks to sensitive locations
- [ ] Implement `_validate_html_path(path: Path, project_root: Path) -> bool`
  - Use existing `_validate_path_in_storage()` from utils.py
  - Check file extension is `.html`
  - Verify file exists and is readable
  - Check file size < MAX_HTML_SIZE

#### 1.3 Safe HTML Parsing Utilities
- [ ] Implement `parse_html_safely(html_path: Path, timeout: int = MAX_PARSING_TIME) -> Optional[Dict]`
  - Check file size before reading
  - Read with timeout protection
  - Use BeautifulSoup in safe mode (no script execution)
  - Handle malformed HTML gracefully
  - Return None on failure (don't crash)
- [ ] Implement `extract_html_metadata(soup: BeautifulSoup) -> Dict`
  - Extract title
  - Extract links (`<a href>`)
  - Extract basic content themes (simple keyword extraction)
  - Strip potentially sensitive content

#### 1.4 File Permission Utilities
- [ ] Implement `set_secure_permissions(path: Path, is_dir: bool = False) -> None`
  - Set `0o600` for files, `0o700` for directories
  - Graceful degradation on Windows
  - Error handling for permission failures

### Deliverables
- `src/waft/core/html_realm_network_security.py` (new file)
- Unit tests for all security functions
- Security validation passes all critique requirements

### Success Criteria
- ✅ All sensitive file patterns excluded
- ✅ Path traversal prevented
- ✅ File size limits enforced
- ✅ Parsing timeouts implemented
- ✅ Safe HTML parsing (no script execution)
- ✅ Secure file permissions set
