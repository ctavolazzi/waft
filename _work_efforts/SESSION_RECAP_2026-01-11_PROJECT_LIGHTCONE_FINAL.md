## Lessons Learned

### AI-AI Collaboration
- **Works**: File ownership separation, iterative approach, clear communication
- **Challenges**: Environment differences (sandbox vs. local), timing coordination
- **Success Factor**: Git as coordination mechanism, clear role division

### Document Generation
- **DocumentEngine**: Excellent for structured documents (MSDS, protocols, memos)
- **FPDF**: Better for complex layouts, visual elements, custom graphics
- **Hybrid Approach**: Use both - DocumentEngine for content, FPDF for style

### Content Creation
- **Hard Science**: Grounding in real theories (Penrose-Hameroff, Many-Worlds) makes horror plausible
- **Corporate Horror**: Bureaucratic justifications more effective than cartoon villainy
- **Variation Strategy**: Maintain style consistency while varying composition, severity, context
