## Objective
Document and demonstrate the practice of "eating our own dog food" - using WAFT's own tools (PDFGenerator, OnePager, ScientificPDFGenerator, LaTeXGenerator) to develop and document WAFT features. This work effort addresses the question: "Why are you not using the tools of WAFT to develop this feature right now?" by actually doing it.
