# Critique: Empirica TUI Dashboard Manual Plan

Date: 2026-01-19

## Findings (Severity-ordered)

### High
- Manual must explicitly list required dependencies and platform-specific requirements (Windows curses).
- Manual should clarify dashboard differences (snapshot vs cascade vs TUI) to prevent misuse.

### Medium
- Manual should include clear troubleshooting guidance for Empirica initialization failures.
- Command reference should note default behavior and expected environment (project root).

### Low
- Add glossary for terms like "CASCADE", "epistemic vectors", "snapshot" to avoid ambiguity.

## Recommendations
- Include a dependency checklist with explicit install commands.
- Provide a comparison table for dashboard types.
- Add troubleshooting with exact error messages and fixes.
