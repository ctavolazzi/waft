## Objective
Develop an evolutionary system where page components (sections, headers, lists, paragraphs, code blocks) evolve over time to maximize content density and adapt to usage patterns. Use the genetic ancestry system to track component genomes, lineage, and fitness metrics. Components will spawn variants, mutate based on performance, and evolve to better suit content demands.
