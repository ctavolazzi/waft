WAFT: The Evolutionary Code Laboratory

Abstract

WAFT (Wide-Area Functional Taxonomy) is an evolutionary code laboratory.

Introduction

WAFT (Wide-Area Functional Taxonomy) is an evolutionary code laboratory. It allows AI agents to modify their own code and evolve through generations.

Architecture

The Substrate

The system has three pillars: The Substrate: Code is DNA - agents can mutate their own source code The Physics: Scint Gym evaluates agents through error handling tests The Flight Recorder: Complete lineage tracking for scientific analysis.
