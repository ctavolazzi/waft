## Objective
Add will to live, luck, decision fatigue, and pleasure/pain attributes to WAFT beings, and implement a centralized "Now" cycle event loop that calculates all system variables, records state to proper locations, and unblocks beings for decisions. This creates a unified temporal framework where all variables are calculated per cycle before beings can make decisions.
