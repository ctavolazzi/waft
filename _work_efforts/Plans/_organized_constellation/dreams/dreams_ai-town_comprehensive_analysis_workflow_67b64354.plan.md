# AI-Town Comprehensive Analysis Workflow Plan (Final - AI Town Version)

## Major Redesign: AI Town with Voting

**Transformation**: Changed from individual analysis workflow to **AI Town democracy** where Beings vote and produce collective output.

**Key Changes**:

1. ✅ **AI Town Formation**: Spawns 3-5 Beings into analysis town
2. ✅ **Distributed Analysis**: Each Being analyzes different aspects
3. ✅ **Voting System**: Command randomly selects some Beings to vote (mostly at random, weighted by relevance)
4. ✅ **Town Choice**: Town votes on PDF format (binder vs single PDF)
5. ✅ **Collaborative Output**: All Beings contribute to final PDF/binder
6. ✅ **Democratic Process**: Majority vote determines decisions, ties broken by Oracle

## Overview

This plan orchestrates an **AI Town workflow** where:

1. **Town Forms**: 3-5 Beings spawn into analysis reality
2. **Distributed Work**: Each Being analyzes different aspects (architecture, algorithms, paper, integration, synthesis)
3. **Democratic Voting**: Command randomly selects some Beings to vote on key decisions
4. **Collective Output**: Town produces PDF/binder based on their vote
5. **Town Reflection**: Beings reflect individually, town synthesizes learnings

**Key Insight**: This is not just analysis - it's a democratic AI town that collectively analyzes and decides together.

## Voting System Implementation

### Voting Mechanics

**Vote Types**:

- **Binary**: Yes/No, Option A/Option B (e.g., binder vs single PDF)
- **Multiple Choice**: Option A/B/C/D (e.g., output style)
- **Ranked**: Rank options 1-3 (e.g., top integration opportunities)
- **Weighted**: Assign weights to options (optional, for skill-based weighting)

**Voting Process**:

1. **Command randomly selects some Beings** (mostly at random) to participate in voting
2. Selection is weighted slightly by relevance (e.g., Being with integration skills more likely selected for integration decisions)
3. Selection size: Typically 50-70% of town (e.g., 2-3 Beings from 5, or 3-4 from 7)
4. Present decision and options to selected Beings only
5. Selected Beings vote (with reasoning)
6. Other Beings are not asked (they don't participate in this vote)
7. Collect votes from selected Beings
8. Calculate results:

                                                - Count votes (from selected Beings only)
                                                - Majority vote wins
                                                - If tie: Oracle breaks tie

9. Document all votes and selection process

**Selection Documentation**:

- Which Beings were selected (and why - relevance weighting)
- Which Beings were not selected (not asked to vote)
- Selection method documented for transparency
- All votes preserved for transparency

### Voting System Code Structure

**Implementation Location**: Can be added to `src/waft/core/town_voting.py` (new file)

**Key Classes**:

```python
class TownVotingSystem:
    """
    Voting system for AI town decisions.

    Handles:
 - Presenting decisions to Beings
 - Collecting votes from selected Beings only
 - Calculating results (majority wins, ties broken by Oracle)
 - Documenting all votes for transparency
    """

    def collect_vote(
        self,
        being: Being,
        decision_id: str,
        question: str,
        options: List[str]
    ) -> Dict[str, Any]:
        """
        Collect vote from a selected Being.
        
        Returns:
            Vote record with being_id, vote choice, reasoning, selected status
        """
        # Being was selected - collect their vote
        vote_choice = self._get_being_vote(being, question, options)
        reasoning = self._get_being_reasoning(being, vote_choice)
        
        return {
            "being_id": being.being_id,
            "vote": vote_choice,
            "reasoning": reasoning,
            "selected": True
        }

    def conduct_town_vote(
        self,
        town_beings: List[Being],
        decision_id: str,
        question: str,
        options: List[str],
        oracle: Optional[Any] = None
    ) -> Dict[str, Any]:
        """
        Conduct a town vote on a decision.

        Returns:
            Complete voting record with results
        """
        votes = []
        for being in town_beings:
            vote = self.collect_vote(being, decision_id, question, options)
            votes.append(vote)

        results = self.calculate_results(votes)

        # Break tie with Oracle if needed
        if results["is_tie"] and oracle:
            results["result"] = oracle.break_tie(question, options, votes)
            results["tie_broken_by"] = "oracle"

        return {
            "decision_id": decision_id,
            "question": question,
            "options": options,
            "votes": votes,
            "result": results["result"],
            "vote_count": results["vote_counts"],
            "non_selected_beings": [b.being_id for b in non_selected_beings],
            "total_votes": results["total_votes"],
            "is_tie": results["is_tie"],
            "tie_broken_by": results.get("tie_broken_by")
        }

    def calculate_results(
        self,
        votes: List[Dict[str, Any]]
    ) -> Dict[str, Any]:
        """
        Calculate voting results.

        Returns:
            Result with winning option, vote counts, tie status
        """
        vote_counts = {}
        for vote in votes:
            choice = vote["vote"]
            vote_counts[choice] = vote_counts.get(choice, 0) + 1

        # Find winner (majority)
        if vote_counts:
            winner = max(vote_counts.items(), key=lambda x: x[1])
            is_tie = list(vote_counts.values()).count(winner[1]) > 1

            return {
                "result": winner[0] if not is_tie else None,
                "vote_counts": vote_counts,
                "is_tie": is_tie,
                "total_votes": len(votes)
            }

        return {
            "result": None,
            "vote_counts": {},
            "is_tie": False,
            "total_votes": 0
        }
```

### Key Decisions the Town Votes On
