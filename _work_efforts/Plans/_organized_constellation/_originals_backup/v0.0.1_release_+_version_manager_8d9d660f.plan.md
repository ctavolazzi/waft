# Fogsift v0.0.1 Release + Version Management System

## Phase 1: Fix the Build System

The current `dist/index.html` has all CSS/JS inline, but `src/` contains modular files that aren't used. We'll refactor to make the build system functional.

**Changes to [dist/index.html](dist/index.html):**
- Remove inline `<style>` block (~468 lines)
- Remove inline `<script>` block (~170 lines)  
- Add `<link rel="stylesheet" href="styles.css">`
- Add `<script src="app.js" defer></script>`
- Keep the inline theme-detection script (prevents FOUC)

**Changes to [scripts/build.js](scripts/build.js):**
- Add HTML template processing (injects version number)
- Copy static assets (404.html, robots.txt, sitemap.xml, images)
- Output clean dist/ folder

## Phase 2: Version Management System

### 2.1 Version Config File

Create `version.json` in root:
```json
{
  "version": "0.0.1",
  "released": "2025-01-14",
  "history": []
}
```

### 2.2 Version Script

Create `scripts/version.js` with commands:
- `npm run version:patch` - Bumps 0.0.X (new components, deletions, fixes)
- `npm run version:minor` - Bumps 0.X.0 (new pages, major features)
- `npm run version:major` - Bumps X.0.0 (breaking changes, redesigns)

Script will:
1. Bump version in `package.json` and `version.json`
2. Prompt for change description
3. Prepend entry to `CHANGELOG.md`
4. Create git commit with message `release: vX.X.X`
5. Create git tag `vX.X.X`

### 2.3 Changelog

Create `CHANGELOG.md` with format:
```markdown
# Changelog

## [0.0.1] - 2025-01-14
### Initial Release
- Complete single-page application
- Light/Dark theme with system detection
- Interactive diagnostic checklist
- Field Notes modal system
- Responsive mobile navigation
```

### 2.4 Release Notes Template

Create `RELEASE_TEMPLATE.md` for documenting releases.

## Versioning Rules (Your Spec)

| Change Type | Version Bump | Example |
|-------------|--------------|---------|
| Button style fix | None (commit only) | - |
| New button | PATCH 0.0.X | 0.0.1 → 0.0.2 |
| Delete component | PATCH 0.0.X | 0.0.2 → 0.0.3 |
| New page | MINOR 0.X.0 | 0.0.3 → 0.1.0 |
| Major redesign | MAJOR X.0.0 | 0.1.0 → 1.0.0 |
