## 🎯 Key Features

### Evolutionary Iteration Process (v0.9.3)

**Generate → Visualize → Inspect → Iterate**

All PDF generators now automatically create PNG screenshots for visual verification. This enables evidence-based debugging and continuous improvement.

**Learn more**: [Evolutionary Iteration Process](Evolutionary-Iteration-Process)

### PDF/PNG Conversion

**Bidirectional conversion with automatic fallback:**

- PDF → PNG: Convert PDF pages to images
- PNG → PDF: Combine images into PDFs
- Multiple backends: pdf2image → ImageMagick → PyMuPDF

**Learn more**: [PDF/PNG Conversion](PDF-PNG-Conversion)

### Document Generation

**Professional PDF generation with multiple generators:**

- `PDFGenerator` - Simple, composable API
- `ScientificPDFGenerator` - Research tools and self-examination
- `ComponentPDFGenerator` - Component-based adaptive generation
- `DocumentEvolutionEngine` - Evolutionary document creation

**Learn more**: [PDF Generation Guide](PDF-Generation-Guide)

## 🔧 Tools & Commands

### Core Commands

- `waft new <name>` - Create new project
- `waft verify` - Verify project structure
- `waft info` - Show project information
- `waft sync` - Sync dependencies

### Document Generation

- `/waft-docs` - Generate field guides, booklets, summaries
- `/waft-status` - System status with multi-level documentation

### Evolution System

- `waft spawn` - Spawn agent variants
- `waft eval` - Evaluate fitness
- `waft evolve` - Evolve to fittest variant
