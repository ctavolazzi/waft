# Gambling Tools

This directory contains tools and utilities for gambling and game documentation.

## Available Tools

1. **The Deck of Fates** - Card visualization system
2. **Session Recap Generator** - Document poker sessions
3. **Story Prompt Generator** - Card-based creative writing
4. **Decision Visualization** - Visualize choices as cards
5. **Game Prototype Documentation** - Document new card games

All tools are located in `examples/` and use The Deck of Fates as their foundation.
