# Documented Games

This directory contains documented poker games and card game sessions.

Games are documented using The Deck of Fates (deckz_poker visualization system) and recorded by The River King.

## Format

Each game should include:
- Game metadata (date, players, game type)
- Hand-by-hand documentation
- Outcomes and statistics
- Visual card representations

## Example

See `examples/generate_poker_session_recap.py` for how to document games.
