# Daily Learning Realm

**Realm Name:** daily_learning_realm  
**Purpose:** Home of The Packrat Being - collects daily learning data and collaborates with The Librarian and The Scribe

## Overview

This Realm is where The Packrat Being lives and works. The Packrat is a timeful Being that:
- Collects research and learning data throughout the day
- Stores everything in its backpack (never deletes, only accumulates)
- Makes noise as it works (characterful logging)
- Visits The Librarian and The Scribe at the end of each day
- Learns from feedback to improve its collection skills

## Structure

```
_realms/daily_learning_realm/
├── README.md (this file)
├── packrat_backpack/
│   └── YYYY-MM-DD_data.json  # Daily accumulated data
└── reports/
    └── YYYY-MM-DD_learning_report.pdf  # Generated reports
```

## The Packrat Being

**Being ID:** Spawned dynamically when server starts  
**Skills:**
- `data_collection`: Starts at 50.0, improves with successful collections
- `research`: Starts at 40.0, improves when findings are validated
- `organization`: Starts at 30.0, improves when Librarian approves
- `memory`: Starts at 60.0 (hoarder trait - high memory)

**Personality:**
- `hoarder=True` - Never deletes data, only accumulates
- `curious=True` - Collects everything, asks questions
- `noisy=True` - Verbose logging with character
- `collaborative=True` - Works well with Librarian and Scribe

## Workflow

1. **Morning:** Packrat Being spawns in this Realm
2. **Throughout Day:** Packrat collects data from:
   - Empirica (findings, unknowns, epistemic state)
   - TheChronicler (file changes, git activity, work efforts)
   - SessionAnalytics (session metrics, code stats, commands)
3. **Trigger Time (9 PM or 3 seconds for dev):**
   - Packrat visits The Librarian (organizes data, filters noise)
   - Packrat visits The Scribe (generates Typst PDF report)
   - Packrat learns from feedback (updates skills)
4. **Next Day:** Packrat continues with improved skills

## Reports

Daily learning reports are generated in `reports/` directory:
- Format: `YYYY-MM-DD_learning_report.pdf`
- Contains: What I Learned, What I Did, Activity Metrics
- Generated by: The Scribe (Pantheon Entity)

## Backpack

The Packrat's backpack stores all collected data:
- Format: `packrat_backpack/YYYY-MM-DD_data.json`
- Structure: Lists of timestamped collections from each source
- Never deleted: The Packrat hoards everything "just in case"
